**CrimePy** is a Python package for crime analysis and spatial statistical modeling, created by Andrew Wheeler (Crime De-Coder LLC). It provides a comprehensive toolkit for crime analysts and researchers, including modules for aoristic analysis (distributing crimes across uncertain time windows), geographic/spatial functions with DBSCAN hotspot clustering and Folium mapping, p-median patrol districting optimization, time series analysis, weighted displacement difference testing for evaluating interventions, dominant set network analysis for identifying key individuals, near-chains clustering for spatiotemporal crime patterns, and spatial point pattern testing. The package is built on research-backed methods and integrates with common data science libraries like pandas, geopandas, scikit-learn, and networkx.
